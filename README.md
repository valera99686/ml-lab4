## Результати (ROC-AUC на валідаційній вибірці, 20 % даних)

| Модель | За замовчуванням | Після підбору | Пошук, с | Навчання підібраної, с |
|---|---|---|---|---|
| Логістична регресія | 0.7514 | 0.7509 | 25 | 3.8 |
| Дерево рішень | 0.5432 | 0.7273 | 44 | 17.8 |
| Випадковий ліс | 0.7248 | 0.7500 | 714 | 43.9 |
| **Градієнтний бустинг** | **0.7662** | **0.7663** | 195 | 8.6 |
| Нейронна мережа | 0.7405 | 0.7418 | 64 | 35.8 |

**Обрано градієнтний бустинг:** найвищий AUC, швидке навчання, мала чутливість до гіперпараметрів. Його перевага над кожною іншою моделлю статистично значуща (парний бутстреп: 95 % інтервали різниці AUC лежать вище за нуль).

Основні спостереження:
- вибір моделі дає значно більше, ніж інженерія ознак: розкид між найкращою та найслабшою підібраною моделлю — 0.039 AUC;
- підбір гіперпараметрів вирішальний для моделей, чиї параметри за замовчуванням не обмежують складність (дерево +0.1840, ліс +0.0252), а для логістичної регресії, бустингу та нейромережі нічого не дає;
- найважливіші ознаки всіх моделей збігаються: `EXT_SOURCE_3`, `GOODS_CREDIT_RATIO` та створена в лабораторній №3 `EXT_MEAN`.

## Схема порівняння

Для кожної моделі: параметри за замовчуванням → підбір гіперпараметрів (Grid Search для дерева, Random Search для решти; 3-кратна стратифікована крос-валідація на підвибірці з 60 000 рядків навчальної частини) → навчання найкращої конфігурації на всій навчальній частині → одноразова оцінка на валідації → важливість ознак. Валідаційна вибірка в підборі не бере участі.
